How It Works

This tool uses the HTML5 Canvas API to re-encode your images at the specified quality level. JPEG and WebP compression is lossy — lower quality = smaller file size. PNG is lossless, so quality has less effect.

Best Settings

For photos, JPEG or WebP at 60-80% quality gives a great balance. For screenshots with text, PNG preserves sharpness. WebP offers the best compression of all three formats and is supported by all modern browsers.
