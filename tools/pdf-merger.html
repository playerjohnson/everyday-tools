    How It Works

    Select your PDF files using the file picker or drag-and-drop. Reorder them by dragging. Click "Merge PDFs" and the tool combines them into a single PDF using the pdf-lib library — entirely in your browser. The merged file downloads automatically.

    Is It Really Private?

    Yes. Unlike most online PDF tools, this one never uploads your files anywhere. Open your browser's network tab to verify — you'll see zero file uploads. Everything is processed using JavaScript in your browser.

    File Size Limits

    Since processing happens in your browser, the limit depends on your device's memory. Most devices handle files up to ~100MB comfortably. For very large files, a desktop browser will perform better than mobile.
